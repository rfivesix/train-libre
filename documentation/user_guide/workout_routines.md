# Create and use workout routines

Create a reusable exercise template, set targets and rest times, then start a workout from it.

## Create a routine

1. Open **Workout** and tap **New Routine**. If this is your first routine, you can also use **Create First Routine** in the empty state.
2. Enter a routine name in **Name of the routine**.
3. Tap **Add Exercise** and choose an exercise from the Exercise Catalog. Repeat to add more exercises. Strength exercises start with three sets; cardio exercises start with one.
4. For each set, enter the target reps and, if useful, weight. For duration or distance-based exercises, fill in the fields shown for that exercise. The weight and distance units follow your selected unit system.
5. To add a set, tap **Add Set** below the exercise. Tap the set-type marker to choose **Normal**, **Warm-up**, **Failure**, or **Dropset**. The **RIR** target is shown when your Training experience setting displays intensity fields.
6. Tap **Save**. A routine needs a name; you can save it before adding exercises and complete it later.

## Edit a routine

1. In **Workout**, find the routine under **All routines** and tap its card. Tap **Edit Routine** if the routine is in view mode.
2. Change the routine name or its set targets. To change the order, press and drag an exercise card.
3. Use the note icon on an exercise to add or change its note. Tap the timer icon to set **Edit Pause Duration**; choose a duration and tap **Save**, or use **Remove Timer** to clear it.
4. Use **Add Exercise** to add another exercise. Use the trash icon (**Remove Exercise**) on an exercise card to remove it, or the trash icon on a set row to remove that set.
5. Tap **Save** when you finish editing. Notes, pause durations, exercise order, and superset connections are saved as you make those changes. If you edit a routine used by a training plan, choose whether to apply the change to the plan too. For connecting exercises as a superset, see [Supersets and edit workout entries](supersets_and_editing.md).

## Start and manage routines

- In **Workout** under **All routines**, tap **Start Workout** on a routine card to begin a workout from that routine. Tap **Free Workout** to start without a routine. For recording sets and finishing, see [Track a workout](tracking_a_workout.md).
- Use the three-dot menu on a routine card to **Duplicate**, **Share**, or **Delete** it. Deleting a routine requires confirmation and permanently removes that template. Workouts already recorded from it remain in workout history.
- To use routines in a schedule, open **Workout** > the **Plan** card. See [Create and follow a training plan](training_plans.md).
