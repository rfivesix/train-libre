# Track a workout

Start a free workout or routine, record each exercise set, and finish with a saved workout summary.

## Start a workout

1. Open **Workout** from the bottom navigation.
2. To begin without a routine, choose **Free Workout**. To follow a routine, tap its **Start** button. Train Libre opens the live workout screen.
3. To add an exercise while training, tap the **Add Exercise to Workout** button and choose an exercise from the catalog.

## Record exercises and sets

1. For each set, enter values in the columns shown for that exercise. Strength exercises use **Weight** and **Reps**; other exercises can show **Distance**, **Time**, or both, according to what that exercise tracks. Weight uses your selected unit system.
2. If the **RIR** column is shown, enter the number of repetitions you think you could still have completed. The field is optional and may not appear for every exercise or setting.
3. Tap the circle at the right of the row to mark the set complete. For a timed set, you can start and stop the set timer with the play/stop control in its **Time** field; completing the set records the elapsed time. Tap the check again to undo completion.
4. Use **Add Set** below an exercise to add another set.

The **Last Time** column can show your previous performance for that exercise. Tap its value to copy the displayed set values into the current row, then mark the current set complete when you are done.

## Rest between sets

When an exercise has a rest duration configured, completing a set starts the rest countdown where the workout sequence calls for a pause. The **Rest** bar shows the countdown; its **−15** and **+15** controls adjust the current timer, and tap **Skip** to end it early. Tap the timer beneath an exercise to change that exercise’s rest duration or turn it **Off**. Free workouts can have no rest duration until you set one.

## Finish the workout

1. Tap **Finish** in the top-right corner.
2. In the finish panel, review or edit the workout title and optionally add notes.
3. Tap **Finish** to save the workout and open its summary. Tap **Cancel** to return to the live workout.

For details about automatic training suggestions and progression, see [Intelligent Workouts](../features/intelligent_workouts.md) and [Workout Progression Engine](../features/workout_progression_engine.md).
