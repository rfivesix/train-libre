## 2024-05-18 - [SQL Injection via Dynamic Table Names in iCloud Sync]
**Vulnerability:** The `ICloudSyncService` iterated through table names retrieved from an attached backup database and dynamically interpolated them directly into `DELETE FROM main."$table"` and `PRAGMA table_info` queries without validation.
**Learning:** Even though the source of the table names is the SQLite schema (`sqlite_master`) of a backup file, backup files are user-provided or externally synced, and can be maliciously constructed (e.g., using a modified zip containing a tampered sqlite file) to execute arbitrary SQL commands if the `table` string contains quote-escaping payloads.
**Prevention:** Always validate external strings that must be used dynamically for table names or column names (where standard parameterized queries `?` cannot be used) with a strict regular expression like `RegExp(r'^[a-zA-Z0-9_]+$')` before interpolation.
