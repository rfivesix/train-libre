## 2025-02-18 - Prevent SQL Injection via External Backup Keys
**Vulnerability:** In `BackupManager._importTable`, the codebase iterated over all keys within the imported backup JSON map and directly interpolated them as column names into a dynamically generated `INSERT OR REPLACE INTO` SQL statement. Because the keys originated from an external file import (untrusted input), a maliciously crafted JSON file could inject arbitrary SQL into the query via the column names.
**Learning:** While parameterizing values with `?` protects against standard SQL injection, column names and table names cannot be parameterized. When processing dynamically typed map inputs for database inserts (like JSON backup restoration), the keys themselves represent a critical attack vector if not validated against an allowlist or a strict regex.
**Prevention:** Always filter or validate dynamic keys (column names) and table names using a strict allow-list or a safe regex pattern like `RegExp(r'^[a-zA-Z0-9_]+$')` before interpolating them into SQL strings. Ignore any keys that do not conform to the expected format.
