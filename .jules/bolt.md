## 2024-05-24 - Two-pointer optimization for sorted history lookups
**Learning:** In pipelines mapping daily historical data across overlapping sliding windows (like SleepRegularityIndex scoring by night), chained `where().toList()` filters inside the `targetNights` loop create an $O(N \times M)$ bottleneck with massive redundant object allocation overhead.
**Action:** When both the target windows and the historical data set are rigorously chronologically sorted, replace the `where()` loop with a continuous two-pointer `while(endIdx < ...)` approach using `List.sublist(0, endIdx)` to slice data natively. This drops time complexity to $O(N + M)$ and executes significantly faster in Dart via contiguous block copying rather than dynamic array generation and closure evaluation per element.
