## 2024-05-19 - Avoid DateTime Object Allocations in Hot Loops
**Learning:** In code processing high-frequency or large-volume time series data (e.g., thousands of heart rate samples in `PulseAnalysisEngine`), repeatedly instantiating `DateTime` and `Duration` objects (e.g., using `.difference()`) within loops creates substantial garbage collection overhead, leading to potential UI jank and battery drain.
**Action:** Always convert timestamps to raw `microsecondsSinceEpoch` or `millisecondsSinceEpoch` before or at the start of hot loops, and perform temporal calculations using primitive integer math (e.g., `~/` for division).
