## $(date +%Y-%m-%d) - Adding Tooltips to IconButtons
**Learning:** Some custom IconButtons lack tooltips (which are important for accessibility/screen readers). It's best to reuse existing localized strings (e.g., `l10n.buttonSave`, `l10n.selectButton`, `l10n.adaptiveRecommendationRecalculateNowAction`) instead of adding new custom strings that require localization in `.arb` files. To reliably find `IconButton` blocks in multi-line Dart code, Python regex/parsing scripts work much better than standard `grep`.
**Action:** When adding missing accessibility labels to icon-only buttons, I will check the `app_en.arb` file for existing matching text strings rather than inventing new keys. I will also use multiline parsing tools to locate these widgets instead of simple line-by-line tools.
