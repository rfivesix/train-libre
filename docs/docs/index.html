Train Libre Documentation

This suite has three sections for different readers. Use the public documentation site ↗ to browse the generated pages.

User Guide#

For people using the app who need task-based instructions, including workouts, plans, nutrition, statistics, notifications, health data, and backups, start with the User Guide overview.

For AI-assisted routines, see Create a workout routine with an AI assistant or its public guide page ↗. It uses the existing routine import format and the OpenExerciseDB exercise search ↗ and JSON catalog ↗ for exercise IDs.

Features & Heuristics#

These pages explain how user-facing features work, what inputs and rules they use, and where their limitations are. They are not step-by-step user instructions or developer implementation guides. Start with Feature Capabilities and Privacy Boundaries, then choose a topic:

Developer Documentation#

For contributors, start with the Developer Documentation overview. The developer section covers system architecture and database lifecycle, data flow and state lifecycle, localization architecture, food search, and home-screen widgets.
