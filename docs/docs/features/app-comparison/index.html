Each app name links to a public developer page or official store listing used as the evidence source. The review covers iOS and Android availability separately and was last checked on 21 October 2026.

The first row shows each app’s broad price model (free, freemium, or subscription); exact amounts vary by country and store. The table records features documented by those sources. Not documented means the reviewed source did not establish the feature; it does not mean the app lacks it. Not included is used only where an app’s own information confirms the absence. Not applicable marks features outside an app's stated scope. Partial availability includes platform or product-form limits.
