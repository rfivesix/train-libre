Set and manage a weight goal

Create a body-weight goal, follow its progress, and review changes to its pace or target date.

Create a goal#

  1. Open Profile and tap My Goals. If no goal is active, tap Set a goal or Set New Goal; to replace the current goal, tap the + button.
  2. Choose Lose weight, Gain weight, Maintain weight, Body Recomposition, or Custom Goal. For a custom goal, enter a title and choose its direction.
  3. On Start Date & Baseline Weight, confirm the start date and baseline. Train Libre looks for the latest recorded weight on or before that date. If none is available, enter a baseline or record a weight measurement; without a baseline, progress waits for the first measurement.
  4. For a weight-loss or weight-gain goal, set Target weight with the ruler or the edit control. The target must be below the baseline for weight loss and above it for weight gain. Maintain-weight goals use a corridor around the baseline instead of a separate target weight.
  5. On Plan Pace & Target Date, choose a weekly pace and duration. Changing one recalculates the other. For a custom duration, tap the date row to choose a date; leave it at No target date if you do not want a deadline. The pace options include Gentle, Moderate, Athletic, Aggressive, and Custom pace.
  6. Add a motivation note if you want, then review the baseline, target, pace, and date. The Drives nutrition switch controls whether the goal can inform adaptive nutrition recommendations.
  7. Tap Activate Goal. If another goal is active, confirm Replace goal to make this one active. The previous goal appears as Superseded in Goal History; your Daily Targets do not change until you apply a recommendation.

You can also choose Set up now during onboarding, or set up the goal later from Profile > My Goals.

Follow progress and adjust the plan#

  1. In My Goals, review the Active Goal card. It shows current weight, baseline, target, progress, and any target date. If it says Waiting for measurement, add a weight in Record body weight and other measurements.
  2. Tap Goal Details to open the full dashboard and weight trend against the planned trajectory. Pull down to refresh after recording a measurement.
  3. Tap Adjust Goal to change the target weight, weekly rate, or date. Choose whether to keep the date or rate fixed; the other part of the plan recalculates. Tap Apply, then confirm Update plan? to save. The revised trajectory starts today and existing measurements remain in your history.
  4. When a review is available, open the Nutrition tab and tap View Review on the Weekly Review card. Review the weight trend and any suggested target changes. Apply targets applies an available nutrition recommendation; Keep goal keeps the current goal while updating daily targets when a recommendation is available. If there is not enough data, tap Continue logging.

Weekly reviews may also offer Adjust weekly rate or Change target date. These open Adjust Goal. Review logic and data requirements are described in Adaptive Nutrition Goals.

Daily Targets are separate: they are the calorie, nutrient, water, and step values used for daily progress. Managing a weight goal does not change them unless you apply a recommendation. See Set daily targets.

Retire or reactivate a goal#

  1. Open Profile > My Goals, then tap Goal Details for the active goal.
  2. Tap Retire goal and confirm. The goal is archived and no longer drives adaptive nutrition.
  3. To reactivate an archived goal, expand Goal History, open the goal, and tap Reactivate goal. Confirm Reactivate. Only one goal can be active at a time; reactivating one retires the other active goal.

Train Libre shows Target reached when the target is met; it does not automatically retire the goal. Use Retire goal when you want to archive it. There is no separate pause or cancel control.
