Supersets and edit workout entries

Connect neighboring exercises as a superset, or correct a saved workout’s exercises, sets, and details.

Connect exercises as a superset#

  1. During a live workout, find the Superset control below the first exercise, beside Add Set.
  2. Tap Superset to connect that exercise with the one immediately below it. The connected exercises are shown together as a superset.
  3. To disconnect them, tap Unlink in the same place.
  4. To include more exercises, connect each neighboring pair in sequence. Drag exercises to change their order; the superset follows the adjacent exercise order.

You can also change superset connections in a saved workout: open Workout Details, tap Edit, then use the superset control below an exercise. Tap Save to keep the changes.

Edit a saved workout#

  1. Open the workout from your workout history and tap Edit on the Workout Details screen.
  2. Edit the values in a set row. Strength exercises show weight and reps; cardio exercises use distance and duration. The effort field is available when the RIR column is shown.
  3. Use Add Set to add a set. Tap the trash icon at the end of a set row to remove that set. Drag an exercise card to change the exercise order.
  4. To add an exercise, tap Add Exercise to Workout at the bottom and choose one from the catalog. To remove an exercise and its sets from this workout, tap the trash icon on its card (the Remove Exercise control).
  5. You can also edit the workout date and time, duration when available, and Notes. Tap Save in the top-right corner to save your edits.

For recording sets and finishing an active workout, see Track a workout.
