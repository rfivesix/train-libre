Record body weight and other measurements

Record body weight, body fat, and circumference measurements, then review how they change over time.

Add a measurement#

  1. Open Statistics and tap the Body measurements shortcut. You can also open the + shortcut menu and choose Add Measurement.
  2. In Measurements, tap Add Measurement.
  3. Set the measurement date and time using the calendar and clock controls. They start at the current date and time; dates from 2020 onward are available.
  4. Enter any values you measured. Available fields are Body Weight, Body Fat, Neck, Shoulder, Chest, Left Bicep, Right Bicep, Left Forearm, Right Forearm, Abdomen, Waist, Hips, Left Thigh, Right Thigh, Left Calf, and Right Calf. You can save several values together for the same date and time.
  5. Tap Save. Weight and circumference fields use the unit system selected in Settings; body fat is entered as a percentage. For unit options, see Getting started.

Review measurement history#

  1. In Measurements, use the chart selector to choose a measurement you have recorded. Only measurements with saved entries are offered; body weight is selected by default when available.
  2. Choose 7D, 1M, 3M, 6M, or MAX to change the displayed period. For periods other than MAX, use the date navigation controls or tap the displayed date range to choose another period. This range is independent of the one selected in the Statistics hub.
  3. Scroll to ALL MEASUREMENTS to review saved entries in that period. Tap an entry to edit its date, time, or values, then tap Save.

The chart and ALL MEASUREMENTS list follow the same date range. Weight charts can show a smoothed trend alongside the recorded values; other measurement charts show the recorded values. Values are displayed using your selected units. If a period has no records, the chart may show an illustrative preview behind an empty-state overlay; it is not your measurement history. For the Body & Nutrition trend view, see Read Body & Nutrition statistics.
