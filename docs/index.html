Train Libre

Own every rep, meal, calorie, and recovery signal.

A private, local-first app for structured workout logging, reviewable AI meal recognition, adaptive calorie guidance, nutrition, hydration, measurements, sleep, pulse, and long-term progress without a mandatory cloud account.

How the models work

Algorithmic transparency

These summaries describe what each feature uses and returns. The linked articles document implementation details and limits.

AI meal capture

AI proposes foods and portions; the app matches them to catalog foods for your review.

  • Nutrition totals use matched food data.
  • Review and edit suggestions before saving.
Learn more

Maintenance estimate

A recursive estimate combines logged intake with a smoothed weight trend and a profile-based starting prior.

  • Uses a 14-day input window.
  • Sparse data can prevent an observation update.
Learn more

Weekly nutrition goal review

A review compares logged progress with the active weight goal and may propose next steps.

  • Data and compatibility checks gate adjustments.
  • Applying a recommendation requires user action.
Learn more

Macronutrient targets

A deterministic allocator divides a calorie target into protein, fat, and carbohydrate targets.

  • Uses body weight and the selected goal.
  • Fixed app rules, not an individualized prescription.
Learn more

Workout progression

When enabled, the workout can suggest a starting target from the latest comparable session.

  • Off by default; suggestions can be edited.
  • Only eligible load-and-repetition sets receive targets.
Learn more

Estimated one-rep max

A logged load and repetition count produce a formula-based strength estimate.

  • Uses the Brzycki equation within its valid repetition range.
  • An estimate, not a measured maximum or safety assessment.
Learn more

Muscle recovery estimate

Eligible completed sets contribute to a time-decaying load estimate for mapped muscles.

  • Uses set details and exercise-to-muscle mappings.
  • A training-load heuristic, not a measure of whole-body recovery.
Learn more

Sleep Health Score (SHS v3)

A 0–100 heuristic combines available sleep duration, continuity, stages, timing, and regularity.

  • Missing inputs affect score completeness.
  • Not a validated clinical score or diagnosis.
Learn more
Privacy & Ownership

Your data starts local.

Train Libre is offline-first. Your tracking data is handled locally by default, and there is no mandatory Train Libre cloud account. Sharing, export, health integrations, catalog refreshes, AI meal recognition, and provider calls happen only through features you choose to use.

1

Local by default

Workouts, meals, measurements, and app state are designed around device-local storage.

2

Portable when needed

Backups, imports, exports, and share sheets make data movable without turning it into a hosted account.

3

Clear boundaries

Optional AI and health features are separate choices, with your API key and platform permissions in your control.
