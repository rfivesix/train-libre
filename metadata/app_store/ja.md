## Description (Full App Store Description)
Train Libreは、データの管理を自分の手に残したまま本格的に記録したい方のための、プライベートかつオープンソースのトレーニング・栄養管理アプリです。オフラインファーストで設計されており、アカウント登録、SNS機能、ゲーム化要素、広告、商用トラッキングやデータの販売は一切ありません。

トレーニング、カロリー、PFCバランス、体重、筋肉の回復状態を、安全なローカルストレージと任意のAppleヘルスケア連携により、1つのアプリで集中して記録・管理できます。

TRAIN LIBREが選ばれる理由:
• オフラインファースト: アカウント登録もネット接続も不要。トレーニングと食事のデータはお使いのデバイス内にのみ安全に保存されます。
• プライバシー・バイ・デザイン: 広告、広告トラッカー、セッション記録、ユーザープロファイルは一切ありません。利用状況統計は任意で初期状態はオフ。健康データは含まれず、IPアドレスを保存することもなく、いつでもオフにして削除をリクエストできます。
• 体系的な筋トレ管理: 単なるゲーム感覚ではなく、漸進性過負荷の原則（プログレッシブ・オーバーロード）に基づいた本格的なトレーニング記録に対応。
• 透明性の高いデータ分析: 明確な計算アルゴリズムに基づき、長期的な身体の変化や傾向を正確に把握できます。

主な機能:

1. 高度な筋トレ・ワークアウト記録
• ウォーミングアップ、メインセット、限界セット、ドロップセットをセット単位で詳細に記録。
• レップ数、重量、RPE / RIR（自覚的運動強度 / 余裕レップ数）の精密なトラッキング。
• 再利用可能なルーチン作成、カスタム種目の追加、過去のトレーニング履歴の閲覧。
• 各セッションに最大4枚の写真を添付できます。カメラ撮影でもライブラリからの選択でも可能で、バックアップにも含まれます。

2. 科学的根拠に基づく栄養管理とTDEE計算
• 食事、カロリー、PFC（タンパク質・脂質・炭水化物）、水分補給、カフェイン、クレアチン、サプリメントの記録。
• 動的TDEE（総消費カロリー）推定: カルマンフィルターとベイズ推定を組み合わせ、毎日の体重と摂取カロリーから本当の維持カロリー（TDEE）を動的に算出。

3. 筋肉の回復状態（コンディショニング）トラッキング
• 視覚的な筋肉回復ヒートマップ: 部位ごとのトレーニング量、強度、直近の負荷から、筋肉の準備状態（リカバリー度）を表示。
• 自己ベスト（PR）、総挙上重量、継続率、体組成・サイズ測定値のグラフィック表示。

4. Appleヘルスケアとのローカル同期
• 任意でヘルスケアデータ（歩数、睡眠、心拍数）を読み込み、ローカルでの回復度計算に活用可能。
• 外部送信なしの完全ローカル処理。

5. BYOK AI食事カメラ機能（オプション）
• BYOK（APIキー持ち込み）方式: ご自身のAPIキーを使用して、AIによる写真からの食事記録機能を利用可能（デフォルトでは無効）。
• 写真・バーコード・音声を1つの画面で: お皿を撮影する、同じ画面で包装食品のバーコードを読み取る、あるいは食事を声で説明する。LiDAR搭載のiPhoneでは、分量を推測ではなく計測します。
• 高精度な食品マッチング: Open Food Factsデータベースと連携したローカル曖昧検索により、AIのハルシネーション（誤認識）を防ぎ正確に記録。
• 100%の透明性: AIが提案した内容は保存前にすべて確認・修正できます。

免責事項:
Train Libreは医療用アプリではありません。リカバリー推定、睡眠記録、バイタルデータは個人でのスポーツ記録およびトレーニングの参考を目的としています。医師による診断や治療の代わりとなるものではありません。

オープンソース & オープンデータ:
信頼性の高いオープンコミュニティデータ（Open Food Factsおよびwgerエクササイズデータベース）を活用して構築されています。全ソースコードが公開されているため、プライバシーに関する説明は「信じる」のではなく「検証」できます。

## Release Notes (What's New / Release Notes in this version)
ワークアウトの写真記録: トレーニングに最大4枚の写真を添付できるようになりました。カメラでの直接撮影やライブラリからの選択に対応し、サマリー画面や履歴詳細からいつでも追加・確認できます。

進行中のワークアウトをいつでも手元に: ナビゲーションの上のバーに、トレーニング中か休憩中か、残り時間、次の未完了セットがどの種目のものかがひと目で分かるようになりました。タップするとワークアウトがバーから広がって開き、ヘッダーのシェブロンでバーに縮んで戻ります。

写真から食事を記録: カメラをお皿に向けるだけで、AIが個々の食品として量・カロリー・PFCに分解します。1回の食事につき最大4枚まで撮影でき、保存前に修正や差し替えが可能です。市販の包装食品は同じ画面のままバーコードで認識されるので、モードを切り替える必要はありません。

分量は推測ではなく計測: LiDAR搭載のiPhoneでは、お皿までの距離と実際に写っている範囲の大きさをカメラが計測し、その値をAIに渡します。計測はAI設定でオフにできます。

中身を話すだけ: マイクボタンを長押しして食事の内容を話してください。写真の代わりにも、写真に添えても使えます。調理法や油、隠れた材料は、写真では分からない情報です。認識は可能な限り端末内で行われ、送信前にテキストを編集できます。

見やすくなった記録: スキャンした食事は写真付きの1つの項目としてまとまり、展開すると材料が表示されます。項目はカロリーの多い順に並び、量とカロリーはどの行でも同じ位置に揃います。

iCloudバックアップに写真も保存: 自動バックアップが食事やワークアウトの写真も一緒に保存するようになり、復元したiPhoneでも記録したときのまま表示されます。復元自体も安全になりました。再起動が不要になり、直前のバックアップは予備として残ります。
